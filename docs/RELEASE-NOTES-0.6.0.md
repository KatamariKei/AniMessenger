# AniMessenger 0.6.0

## Your shared journey

- Discover up to three source-supported character revelations, with clearer clues, broader wiki routing and automatic research after the opening scenario image.
- Unlock discoveries naturally through conversation, with a dismissible notification, an original warm fanfare and optional reward artwork.
- Earn persistent achievement points, visible in your user dossier. Time well spent tracks three different verified shared activities; Getting to know you recognizes three confirmed discoveries.
- Final discovery celebrations appear before the related achievement, with a short pause between them.
- Completed discoveries show a concise completion message instead of research controls and empty clues.

## Memories that keep growing with you

- More selective capture, consolidation of repeated details and evidence-backed updates to fulfilled commitments.
- A 240-memory active target, not a storage ceiling: lower-priority overflow is archived rather than automatically deleted and remains available for relevant recall.
- Earlier wording and details are preserved when memories are refined. Superseded plans are not treated as outstanding promises.
- Full-chat rescans use the same admission, update, resolution and archival rules as live reviews. Long chats are processed in resumable batches without the former eight-batch ceiling.
- Memory search, source evidence and health reporting make the collection easier to review.

## Profiles, scenes and images

- A redesigned user dossier with mobile-friendly controls, generated or uploaded portraits, editable appearance and explicit optional local vision analysis.
- Remove full-screen character-dossier background blur to reduce scrolling rendering work, and route Persona/Megami Tensei titles to their shared franchise wiki.
- Better continuity for locations, shared travel, posture, clothing and garment removal, including explicit location corrections that override stale model state.
- More grounded snapshot prompts, larger discovery artwork and recoverable image-generation failures.

## Updating safely

Use the new Windows package to update an existing installation. Application files are replaced separately from private chats, memories, artwork references, settings and achievement points.

The default image model and recommended image workflow are unchanged in this release. Previously deleted memories are not automatically recovered. Memory improvements and discovery recognition still depend on the selected local model and available evidence; source coverage and exact image continuity cannot be guaranteed.

This release passed automated install/update rehearsals and user-reported 3090 functional smoke checks. A known first-person narration drift after switching an existing chat to Narrative Mode is deferred to the next release.
